This folder contains the new data constructed for the replication package.

File descriptions:

- `Loewenberg_1781_1820_it_raw.csv` contains the operas included in Loewenberg (1973) for the 1781-1820 period. The relevant source pages are provided in the `Data_Sources` folder.
- `Composers_Italian_Born.csv` includes all composers active in Italy between 1781 and 1820 and indicates whether each composer was born in Italy.
- `Opening_Night_Operas_it_raw.csv` contains all operas by Italian-born composers that premiered between 1781 and 1820.
- `Opening_Night_Operas_it_cleaned.csv` is the cleaned state-year version of the opening-night opera data.

Where Italy refers to Italy's 1900s, as defined in GM2020. In practice, this is the same as Italy today excluding Friuli-Venezia Giulia and its capital Trieste.
The remaining files in this folder are alternative samples that exclude Milan, Venice, or both.
