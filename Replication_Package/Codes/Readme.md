This folder contains the code I use to support my analysis of the comment. It is in a mixture of R and Stata, owing to my use of R generally and the original replication package of GM2020 being in Stata. Running the master.R should be straightforward and should require no changes to any paths, just open the package located at the Replication_Package folder. To run the Master.do, clone the repository and change the path of working directory in Master.do once to the root of the repository. After this, all R and Stata files should run without any need to change paths. The input data is either from Data_New, which is data I collected, or from Data_GM2020, which is a folder containing all the data from the JPE replication package of GM2020.
